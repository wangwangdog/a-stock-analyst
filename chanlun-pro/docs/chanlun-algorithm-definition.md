# chanlun-pro cl.py 缠论算法定义

根据 chanlun-define.md 整理，作为 cl1.py 实现的算法参考。

## 一、K线包含处理原则（CLKline）

1. **目标**：原始K线 → 缠论K线（CLKline），消除包含干扰
2. **包含判定**：A.high≥B.high ∧ A.low≤B.low（A包含B）或反之
3. **方向性合并**（关键）：
   - 上升趋势（前一根高低点均小于当前）：向上处理（高取更高，低取更高）
   - 下降趋势（前一根高低点均大于当前）：向下处理（高取更低，低取更低）
4. **输出**：date, index/k_index, h/l/o/c, n（合并计数）, klines（原始集合）

## 二、分型核心定义（FX）

1. **基础**：基于缠论K线（CLKline），不是原始K线
2. **三K判定**：连续三根CLKline中：
   - 中间K线高点是三根中最高的，低点也是三根中最高的 → 顶分型
   - 中间K线低点是三根中最低的，高点也是三根中最低的 → 底分型
3. **锚点**：中间那根CLKline
4. **分型是纯定义**：去重、顺序约束、末尾处理属于成笔规则

## 三、笔（BI）知识库

1. **成笔基本条件**：
   - 顶-底 或 底-顶 交替连接
   - 方向一致性：顶→底 为下笔（起点价>终点价），底→顶 为上笔
   - 跨度≥5根CLKline（含两端）
   
2. **约束规则**：
   - 顶分型区间至少部分高于底分型区间
   - 不允许跳连
   - 后向校验（确认性）
   
3. **Rule 3（关键替换规则）**：
   - 全局后续更极值回溯替换：后续若出现更高顶/更低底，允许回溯替换
   
4. **特殊成笔**（跨度<5时）：
   - 本级别顶=高一级别某个顶分型顶值
   - 本级别底=高一级别某个底分型底值

## 四、笔中枢（BI-ZS）知识库

1. **成立条件**：
   - 高一级别笔方向决定候选三笔形态（up→下-上-下，down→上-下-上）
   - 三笔必须有价格重叠区间
   
2. **边界规则**：
   - 一个中枢只归属一个高一级别笔，不得跨越边界
   
3. **同段不重叠**：
   - 优先解释为延伸，条件满足才新生
   - 中枢延伸：后续走势在ZD~ZG内震荡，中枢区间不变，延长至离开段起点
   - 中枢新生：第三类买卖点后形成新中枢，区间无重叠
   
4. **完成态**：done=True/False
5. **标准字段**：type, trend_type, done, zg, zd, gg, dd, line_num, level, index

## 五、走势类型（trend_type）

- **趋势上涨**：上涨方向≥2个中枢
- **趋势下跌**：下跌方向≥2个中枢
- **盘整上涨**：上涨方向=1个中枢
- **盘整下跌**：下跌方向=1个中枢
- **结束判定**：出现反向第三类买卖点，原走势结束
